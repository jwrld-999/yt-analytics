Privacy Policy

Last updated: November 2, 2026

YT AI Intel ("the app") is a personal automation used only by its developer. This policy explains how the app uses Google user data.

Data the app accesses

When the developer signs in with Google, the app asks for these permissions:

  • Google Drive (drive.file): the app can only see files that it created itself, which are the weekly reports and the history spreadsheet. It cannot see any other Drive files.
  • Google Sheets and Google Slides: to create and update the report spreadsheet and slide deck.
  • Gmail (send only): to email the weekly report to the developer. The app cannot read, delete, or manage email.

How the data is used

The app uses these permissions only to create the weekly report, save it to the developer's own Google Drive, and email it to the developer. The report contains public YouTube statistics.

Sharing and storage

Google user data is not sold, shared with third parties, or used for advertising. OAuth tokens are stored privately, both on the developer's computer and in an encrypted secret store used to run the scheduled job. No Google user data is kept anywhere else.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
